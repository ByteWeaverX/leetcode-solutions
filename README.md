# LeetCode Solutions

A running log of LeetCode problems solved, auto-synced from submissions using [LeetSync](https://github.com/rzashakeri/LeetSync).

## 📊 Stats

Solutions are added automatically as I solve problems on LeetCode, so this repo grows continuously rather than reflecting a fixed count. Browse the folders above for the current set.

- Languages: **C++** (primary), **SQL** (database problems)

## 📁 Structure

Each folder is named after the problem (e.g. `1-two-sum`) and contains:
- The solution file (`.cpp` or `.sql`)
- A `README.md` with the original problem statement, pulled automatically from LeetCode

Commits are auto-generated by LeetSync at submission time and include runtime/memory stats from LeetCode's judge — that's why commit messages look like `Time: 2 ms (72.80%) | Memory: 14.8 MB (35.91%)` rather than typical commit messages.
